
# Pandas DataFrame Practice

This repository contains my practice work with Pandas DataFrames in Python. It focuses on learning how to create, manipulate, analyze, and organize structured data using Pandas.

## Topics Covered
- Creating DataFrames and Series
- Data selection and indexing
- Filtering rows and columns
- Sorting data
- Handling missing values
- Statistical operations
- GroupBy and aggregation
- Merging and joining DataFrames
- MultiIndex DataFrames
- Data analysis basics

## Libraries Used
- Python
- Pandas
- NumPy

## Purpose
To strengthen my data manipulation and analysis skills and build a foundation for Data Science through hands-on practice with structured datasets.
